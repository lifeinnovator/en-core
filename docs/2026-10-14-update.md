# En-Core 구축 현황과 업데이트 기록

확인일: 2026-10-14 (Asia/Seoul)

## 배경과 확인된 사실

- 사용자는 En-Core를 Life Innovation Lab에서 수행하는 프로그램으로 정리하고, 구축 배경 조사부터 실제 페이지 업데이트까지 요청했습니다.
- 사용자가 확인한 현재 단계: **기획·개발 중, 시범 운영 협의 가능**.
- Life Innovation Lab의 목적은 **AI 시대에 사람의 자기존중 회복**을 위한 콘텐츠와 프로그램 개발입니다. 기획자의 배경은 경영혁신 컨설턴트·은퇴설계전문가(ARPS)입니다.
- 저장소: `lifeinnovator/en-core`, 기본 브랜치 `main`.
- 점검 시작 커밋: `15198fcd120a8b53009df981e5ea56f21bef1b40`.
- 2026-07-22에 파일 업로드 커밋 2건이 있습니다. 작성 도구를 식별하는 기록은 없어서 Claude 작성 여부는 확인되지 않았습니다.
- 운영 URL의 `index.html`, `contact.html`, `robots.txt`, `sitemap.xml`은 점검 시작 시 저장소 파일과 일치했습니다(줄바꿈 정규화 비교).
- 기존 커밋의 GitHub Vercel 상태는 success이고 `lifeinnovators-projects/en-core` 프로젝트를 가리켰습니다.
- HTML/CSS/브라우저 JavaScript 기반 정적 사이트입니다. 서버·DB·패키지 매니페스트·빌드/테스트 설정은 없습니다.
- 문의 폼은 FormSubmit을 통해 기존 공개 연락 이메일로 POST합니다. 활성화와 실제 수신 여부는 소스만으로 검증할 수 없습니다.
- 저장소에는 교안, 운영 실적, 비용표, 강사진 목록, 기존 기획 대화가 없습니다. 별도 서비스인 Encore Life 상담 도구와 혼합하지 않습니다.

## 변경 범위와 대안

- `index.html`: Lab 소개, 개발 상태, 교육 문구, FAQ, 과정별 연결, 반응형 보완.
- `contact.html`: 시범 운영 안내, Lab 표기, 과정 사전 선택, 입력 접근성·가시성, 누락된 head 닫기 태그 보완.
- `robots.txt`, `sitemap.xml`: 운영 도메인 수정.
- `README.md`, 이 문서: 소스·배포·운영 상태·검증 방법 기록.
- 기존 네이비/앰버 디자인, 인코어 브랜드, 9개 과정, 기존 FormSubmit 발송 경로 유지.
- 대안인 전체 디자인 개편, 프레임워크 전환, 자체 문의 백엔드 구축은 이번 목적에 필요하지 않아 제외했습니다.
- 되돌리기: 업데이트 커밋을 revert하고 Vercel 배포와 운영 페이지를 확인합니다. 데이터 마이그레이션은 없습니다.

## 후속 확인이 필요한 항목

1. 실제 시범 운영 전, FormSubmit 활성화와 메일 수신을 담당자가 확인해야 합니다. 이번 작업은 테스트 이메일을 보내지 않습니다.
2. 기존 개인정보 동의문의 ‘처리 완료 후 지체 없이 파기’ 약속이 실제 메일 관리 및 외부 서비스 처리 방식과 일치하는지 확인해야 합니다. 이번 작업은 법적 적합성을 인증하지 않습니다.
3. 개발이 완료되는 과정부터 교안 샘플, 확정 운영 조건, 기획자 프로필 증빙, 시범 운영 결과를 추가합니다. 실적·인증 기관·비용을 임의로 만들지 않습니다.
4. 기존 OG 이미지는 인코어 브랜드 자산을 유지합니다. Lab을 포함한 새 공유 이미지는 별도 디자인 작업으로 검토할 수 있습니다.

## 검증 기준

- 두 HTML의 문법·인라인 JavaScript 파싱, 중복 ID·내부 링크·이미지 경로 검사.
- 9개 과정 링크와 문의 선택 값 매핑, 잘못된 URL 입력의 기본값 유지.
- 데스크톱·모바일에서 소개, 과정, FAQ, 문의 폼 확인.
- 필수 항목 검증은 실제 외부 전송 없이 확인.
- 빌드·타입 검사: 관련 빌드 도구 및 TypeScript가 없는 정적 사이트이므로 해당 없음.
- 배포 완료 판단: GitHub/Vercel 성공 상태와 운영 URL의 변경 파일 내용 일치 확인.
